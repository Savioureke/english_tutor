# Eduleb - Online Education & English Tutoring Platform

Modern, fully responsive React + Tailwind CSS web application transformed from the Eduleb educational template. Built with Vite and optimized for deployment on Vercel.

## 🚀 Features

- **Framework**: React 18 + Vite (SPA)
- **Styling**: Tailwind CSS v3 with custom brand tokens
- **Typography**: Jost (Headings) & DM Sans (Body)
- **Icons**: Lucide React
- **Responsiveness**: 100% Mobile, Tablet, and Desktop responsive
- **Pages**:
  - Home 01 (`/`) & Home 02 (`/home-2`)
  - About Us (`/about`)
  - Courses Catalog (`/courses`) & Course Details (`/course/:id`)
  - Instructors Directory (`/instructors`) & Instructor Details (`/instructor/:id`)
  - Pricing Plans (`/pricing`)
  - FAQ Page (`/faq`)
  - Blog & News (`/blog`) & Single Post (`/blog/:id`)
  - Contact Us (`/contact`)
  - 404 Not Found (`*`)

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select this GitHub repository (`english_tutor`).
4. Framework Preset: **Vite** (auto-detected).
5. Click **Deploy**.
